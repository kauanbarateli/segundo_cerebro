SEGUNDO CÉREBRO · SISTEMA VISUAL

Um lugar para tudo o que importa.

Uma linguagem visual silenciosa para tarefas, notas, agenda, arquivos, hábitos, projetos, finanças e informações pessoais viverem como partes do mesmo cérebro.

Princípios

A interface atual já tem uma personalidade forte: muito espaço negativo, títulos editoriais, cards brancos e preto como decisão. O sistema abaixo formaliza isso.

01

Menos interface

O chrome recua. Conteúdo, contexto e próxima ação ficam em primeiro plano.

02

Preto é decisão

CTA e seleção ativa usam preto. Cores vivas não competem com a hierarquia.

03

Cor tem significado

Teal, violeta e estados semânticos aparecem somente quando carregam informação.

Marca

Um “2” contínuo com dois terminais. Ele combina a ideia de segundo cérebro com o fluxo captura → conexão → recuperação.

Clear space: ¼ do símbolo · mínimo: 24px símbolo / 136px lockup · sem gradientes

Cores

Base quente e quase monocromática. O off-white reduz dureza sem parecer bege; o preto cria foco. Use aproximadamente 90% de neutros e 10% de cor semântica.

Acessibilidade

Minimalismo só funciona quando continua legível, operável e explícito.

Obrigatório

  • Área interativa mínima de 44 × 44 px.
  • Foco visível em teclado.
  • WCAG AA para texto.
  • Ícones isolados com nome acessível.
  • Status nunca comunicado apenas por cor.

Movimento

  • Hover: 120ms.
  • Transição de superfície: 180ms.
  • Easing: cubic-bezier(.2,.75,.25,1).
  • Respeitar prefers-reduced-motion.
